# EduCore SMS

EduCore SMS is a modern, secure, scalable School Management System built for Primary and Secondary Schools.

## Features

- Authentication
- Role-Based Access Control (RBAC)
- Student Management
- Teacher Management
- Parent Portal
- Attendance
- Results & Report Cards
- School Fees
- Reports
- Dashboard Analytics
- Notifications
- Audit Logs

---

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- TanStack Query

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
